┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 QUICK FIXES                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Problem: "Connection refused"
→ Install: pip install -r requirements.txt
→ Then start server again

Problem: Microphone not working
→ Allow permission when browser asks
→ Check Settings → Privacy → Microphone

Problem: Voice not recognized
→ Speak louder and more clearly
→ Try shorter phrases
→ Check microphone is connected

Problem: No audio output
→ Check speaker volume
→ Allow browser to play audio

Problem: Text input not working
→ Click in input field first
→ Make sure it's focused (blue border)
→ Try pressing Enter instead of button

│ 💡 TIPS & TRICKS                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

✓ For better voice recognition:
  - Speak clearly and pause between words
  - Use shorter phrases (2-5 words)
  - Reduce background noise
  - Use a good quality microphone

✓ For faster responses:
  - Use text commands for simple requests
  - Voice works best for complex instructions

✓ For testing without voice:
  - Use text input field instead
  - No microphone needed for text

✓ For development:
  - Use --reload flag (auto-restart on code change)
  - Check browser console frequently
  - Use F12 DevTools for debugging
